# Tests responsive

| Largeur | Changement | Pourquoi |
|---|---|---|
| Moins de 45em | Le header est en colonne. | Les éléments ont plus de place. |
| À partir de 45em | Le header est sur une ligne. | Le logo, le menu et le bouton peuvent tenir ensemble. |
| À partir de 64em | L’accroche et l’aside sont côte à côte. | L’écran est assez large pour deux colonnes. |

## Largeurs testées

- 375px : pas de défilement horizontal.
- 768px : le contenu reste lisible.
- 1440px : les deux colonnes sont affichées correctement.
