# Parcours clavier

## Avant les corrections

Le parcours a été réalisé uniquement avec les touches Tab, Maj + Tab et Entrée.

- Le lien d’évitement devient visible lorsqu’il reçoit le focus.
- Tous les liens, boutons et champs sont accessibles.
- Le focus reste visible pendant tout le parcours.
- L’ordre de navigation correspond à l’ordre visuel de la page.
- Aucun élément n’est ignoré.
- Le focus ne reste piégé dans aucune partie de la page.

## Après les corrections

Le parcours a été vérifié à nouveau uniquement avec le clavier.

- Le bouton du menu reçoit un focus visible.
- Le menu s’ouvre et se ferme avec Entrée et la barre d’espace.
- Les liens du menu ne reçoivent pas le focus lorsque le menu est fermé.
- La fenêtre modale s’ouvre avec Entrée.
- Le focus reste dans la fenêtre modale lorsqu’elle est ouverte.
- La touche Échap ferme la fenêtre modale.
- Après la fermeture, le focus revient au bouton qui a ouvert la modale.
- Les messages du formulaire sont annoncés et associés aux champs concernés.
- Lors d’un envoi invalide, le focus est dirigé vers le premier champ incorrect.
- Aucun focus n’est perdu ou piégé de manière incorrecte.
